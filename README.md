# TodoApp - Projeto C# para atividade de DevOps

Projeto simples em C# para praticar:

- Git
- Branches
- Commits
- Pull Requests
- Testes automatizados
- Docker
- CI com GitHub Actions

## Funcionalidades

- Adicionar tarefa
- Listar tarefas
- Marcar tarefa como concluída
- Remover tarefa

## Como executar

```bash
dotnet run --project TodoApp
```

## Como executar os testes

```bash
dotnet test
```
